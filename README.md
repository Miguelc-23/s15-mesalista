## Sistema de Reserva de Mesas para un Restaurante Pequeño
Este sistema ha sido desarrollado para optimizar y agilizar el proceso de gestión y reserva de mesas de un restaurante pequeño. La plataforma centraliza el flujo operativo permitiendo consultar mesas disponibles por fecha y hora, realizar reservas de manera ágil y registrar la llegada del cliente al establecimiento de forma ordenada.

## Funcionalidades Principales
Consulta de mesas disponibles por fecha y hora en tiempo real.
Reserva rápida de una mesa para los clientes.
Registro de la llegada del cliente al local gestionado por el anfitrión.
Control y visualización de actores: cliente y anfitrión.
